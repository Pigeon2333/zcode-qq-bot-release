# ZCode QQ机器人 · 发布仓库

这里只存放 [ZCode QQ机器人](https://github.com/Pigeon2333/zcode-qq-bot) 的 Windows 安装包，
供应用内「自动更新」下载（公开、无需 Token）。

## 下载

到 [Releases](../../releases) 下载最新的 `ZCodeQQBot-v*-win-x64.zip`，解压双击
`ZCodeQQBot/ZCodeQQBot.exe` 即可。

## 自动更新

应用「关于」页 → 检查更新 → 下载并安装。若你的「更新源」还指向旧仓库，
改为 `Pigeon2333/zcode-qq-bot-release` 即可零配置更新。

## 说明

- 主仓库（源码/文档）见上方链接
- 数据（人设/记忆/Key）保存在本机 `~/.zcode-qq-bot/`，更新与卸载程序不会触碰
